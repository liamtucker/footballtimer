# rota

A display for casual six-a-side. It says who is in goal and who is the sub, and
it changes on a timer.

Nobody wants to go in goal. The reason that is hard to fix is not that the turns
are difficult to track — it is that saying *"you're next"* costs something, and
the people willing to spend it are exactly the people who then don't go in goal.
The quiet ones end up in there twice as long.

This puts the instruction in a screen and a voice, so it costs nobody anything.

- [spec.md](spec.md) — what it does and the rules it enforces
- [plan.md](plan.md) — the build order

One static page. No backend, no accounts, no build step. Add to home screen,
works with no signal.
